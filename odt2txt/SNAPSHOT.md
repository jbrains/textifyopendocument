# Reference snapshot of odt2txt

This directory is a plain copy (no git history) of the upstream
[odt2txt](https://github.com/dstosberg/odt2txt) repository, kept as the
reference implementation that `textifyopendocument` reimagines.

- Upstream: https://github.com/dstosberg/odt2txt
- Snapshot commit: `56b945e7304b899db78a658cc7c60a3c9afd984d`
  (`56b945e`, 2017-09-28, "Convert xml-protected spaces to real spaces")
- Snapshot taken: 2026-10-24
- License: GPL-2 (see GPL-2 in this directory and LICENSE in the project
  root)

odt2txt is not under active development; this snapshot is expected to remain
current.
