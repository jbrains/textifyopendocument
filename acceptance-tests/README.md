# Acceptance test data

Hand-supplied real-world documents used to validate `textifyopendocument`.

## Final Boss

The big spreadsheet that the original `odt2txt` needs 15+ minutes to process
goes here. It is the final acceptance test for the Rust rewrite.

Place the file in this directory. To keep it out of version control (large,
possibly private data), add its name to this repository's `.gitignore` rather
than committing it.
